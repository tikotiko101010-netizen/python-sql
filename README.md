# Python & SQL Development Portfolio

Welcome to my portfolio repository! Here, I collect my best practical solutions, clean code implementations, and database scripts developed during my training and independent practice. 

The core of this repository showcases my work from the comprehensive Python and SQL tracks by BeeGeek (Stepik platform).

## 📁 Repository Structure

*   **`MultiKeyDict.py`** — A custom dictionary implementation supporting aliases for keys, using mutable list containers for synchronized references. Demonstrates advanced encapsulation.
*   **`predicate.py`** — A decorator class that enables logical operations (AND, OR, NOT) on functions via operator overloading (`&`, `|`, `~`). Uses lazy lambda compositions.
*   **`selfie.py`** — An implementation of the Memento design pattern that captures, tracks, and restores object states using `__dict__` and deep copying.
*   analytical_queries.sql — Advanced database scripts and queries demonstrating production-ready SQL features.
